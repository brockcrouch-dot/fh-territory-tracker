# FH Territory Tracker — Connected Build

This build is already configured with the Supabase Project URL and publishable browser key.

## First-time setup
1. Run `schema-fix.sql` once in Supabase SQL Editor if you previously ran the earlier schema.
2. In Supabase Authentication, make sure Email sign-in is enabled.
3. Host these files on HTTPS.
4. Open the hosted app in Safari on iPhone/iPad.
5. Open Cloud Settings, create an account, and sign in.
6. Use the same login on both devices.

Never add a Supabase secret/service-role key to the browser app.
